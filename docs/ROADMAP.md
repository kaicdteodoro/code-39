# Roadmap

## Current scope

- Local CLI generation of Code 39 barcodes without checksum
- Batch PDF output
- Duplicate prevention and append-only batch history
- Basic unit and CLI tests

## Next improvements

- Add configurable print layouts for specific graphic suppliers
- Add PNG export mode for individual references
- Add release packaging and downloadable binaries
- Add CI badge and tagged release flow

## Explicitly out of scope for now

- External integrations
- Web dashboard
- QR Codes
- Real-time tab lifecycle management
